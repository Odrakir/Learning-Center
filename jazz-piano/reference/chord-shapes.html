7th Chord Shapes

Interval patterns for jazz's core chord colors. Learn the shape once — it transposes to every root unchanged.

Read it as half-steps from the root

Every 7th chord is a root plus three notes stacked above it, each a fixed number of half steps up. The formula never changes — only where you plant the root does.

ChordFormula (half steps from root)Character
Major 7 (maj7)0 · +4 · +3 · +4bright, lush — "home"
Dominant 7 (dom7 / "7")0 · +4 · +3 · +3bluesy, wants to resolve
Minor 7 (min7)0 · +3 · +4 · +3mellow, dark
The move: the root and 5th (+7 half steps) never change. Only the 3rd and 7th shift: maj7 keeps both "major" (+4 / +11 from root); dom7 flattens just the 7th (+4 / +10); min7 flattens both the 3rd and 7th (+3 / +10). Flat the 7th, then decide whether the 3rd is flat too — that's the whole family tree. See Lesson 3 for the full walkthrough.
